# Alexis Otero — Portfolio

Personal portfolio site built with React 19 and Vite. Includes About, Projects,
Contact, Games, Music, and Playground sections, with English/Spanish
localization.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Tech stack

- React 19 + Vite
- ESLint
